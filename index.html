Partner-facing AI chatbot

Proposed and led the design of Snap's first customer-facing AI agent: a support assistant for partner developers, built on AWS Bedrock with Knowledge Bases, Guardrails and AgentCore. Delivery is phased, starting with a deliberately small, low-cost MVP.

  • ▸Safe by design: a strict scope boundary, grounded answers drawn only from approved documentation, and strong tenant isolation.
  • ▸Cost-aware: out-of-scope requests are stopped before they consume model resources.
  • ▸Governed: iterated through more than a dozen documented revisions with engineering, security and operations reviewers, including a formal security assessment.
  • ▸Measured: success tracked through answer quality, grounding, latency, cost and safety targets.

AI-powered, risk-based QA expansion

Redefined the scope of QA for the merchant platform. Beyond manual and automated feature testing, the approved proposal adds performance, security, API-specification and API-standards verification, orchestrated by AI agents inside the IDE and shaped together with the QA Manager and QA team.

  • ▸Evidence-based release decisions: blocking criteria based on agreed risk metrics, with time-boxed, approved exceptions.
  • ▸No lost findings: every actionable issue becomes owned, de-duplicated and traceable technical debt.
  • ▸AI that extends QA, not replaces it: agents generate test cases from acceptance criteria and implemented behavior, surface edge cases and free up QA bandwidth.
  • ▸Safe rollout: pilot first, thresholds validated before enforcement, and existing quality gates left intact.

04 · Featured project
Built from scratch

merchant-art-agents — an agent factory for the dev cycle

A reusable library of Cursor agents, skills and rules that standardizes how our services are reviewed, upgraded, documented and released. One initializer agent installs the right toolkit into any repo based on its stack — Java Spring Boot, serverless, Node, Next.js/React/Prisma, PHP Laravel/Magento/WooCommerce, Liquibase.

Orchestrators detect the stack, delegate to specialist sub-agents, run gated procedures (build, tests, coverage, OWASP, N+1, acceptance criteria from Jira, Confluence tech docs) and end in a clear pass/fail report. Guardrails like no automatic git writes, freshness gates and token-saving rules keep autonomy safe and cost-aware.
